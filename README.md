# Colorado Battletech Custom Units

Custom Battletech units in use by Colorado Battletech Denver and Colorado Springs

To access these units in https://mekbay.com/, navigate to Options > Advanced. Then under Additional unit servers add this URL: https://raw.githubusercontent.com/Oddmajo/cobt-customs/refs/heads/main/

## First Time Setup

1) Clone this repository to your computer

2) Ensure the correct java version is installed -- requires at least Eclipse Temurin 21 JDK

(Windows) `java --version`
~~~
openjdk 21.0.11 2026-04-21 LTS
OpenJDK Runtime Environment Temurin-21.0.11+10 (build 21.0.11+10-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.11+10 (build 21.0.11+10-LTS, mixed mode, sharing)
~~~

If needed, install the correct java version:
(Windows) In terminal as admin run `winget install EclipseAdoptium.Temurin.21.JDK`

4) Download the Unit Exporter from the Releases here: https://github.com/pavelbraginskiy/mekbay-customs-sample

5) Extract the tool. This repository is setup for ease of use; the tool tool can be extracted into `workspace/MegaMekLab-SVGMassPrinter`. The remainder of this README will assume that this tool is extracted to this location.

## SVG Creation

To create SVGs, use svgmassprinter.bat (available from https://github.com/pavelbraginskiy/mekbay-customs-sample) and follow the directions there as necessary.

Add or remove raw sheets as necessary from `workspace/sheets-raw`. 

The `workspace/sheets-generation` directory has been created to assist with this. Navigate to this directory, and run the following command in order to pull all raw sheets into a single flat directory for use with the svgmassprinter tool: `cp ..\sheets-raw\*\* .`.

Navigate to the root of the MegaMekLab-SVGMassPrinter tool, and run the command generate the SVG files: `.\bin\svgmassprinter.bat --skip-equipment --units "<input_dir>" -o "<output_dir>"`

Example: `.\bin\svgmassprinter.bat --skip-equipment --units "..\sheets-generation\" -o "../.."`

Note: Directory path is finicky. Known Issues:
* Must be in root of download (default name: MegaMekLab-SVGMassPrinter)
* Whitespace
* Nested Directories

## Git Tips and Tricks

* Git can easily be installed through windows powershell with `winget install --id Git.Git -e --source winget`. This README assumes most work is done through a windows terminal (such as powershell).

* MegaMekLab seems to generate .mtf and .blk files using unix EOL characters rather than windows EOL characters. Git by default might automatially swap these. It is unknown if swapping will cause issues with either MegaMek, the svgmassprinter, or Mekbay. To disable this in git, use the following command: `git config --global core.safecrlf false`.
